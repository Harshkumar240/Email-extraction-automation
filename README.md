# CodeAlpha Task Automation - Email Extractor

## Project Description

This project is a simple Python automation tool developed as part of the CodeAlpha Python Programming Internship.

The program reads a text file, automatically finds email addresses, removes duplicate email addresses, and saves the results into a separate file.

## Features

- Reads text from a file
- Automatically detects email addresses
- Removes duplicate emails
- Displays extracted emails
- Saves results to a text file

## Technologies Used

- Python
- Regular Expressions (`re`)
- File Handling
- Lists
- Sets

## Files

- `email_extractor.py` - Main Python program
- `sample_emails.txt` - Input text file
- `extracted_emails.txt` - Generated output file

## How to Run

Open the terminal in the project folder and run:

```bash
python email_extractor.py
